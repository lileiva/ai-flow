# textkit

Tiny string utilities.

- `slugify(str)` turns a title into a URL slug.
- `truncate(str, max, { ellipsis })` shortens a string to at most `max` characters.
- `capitalize(str)`, `camelCase(str)`, `kebabCase(str)` change letter case.
