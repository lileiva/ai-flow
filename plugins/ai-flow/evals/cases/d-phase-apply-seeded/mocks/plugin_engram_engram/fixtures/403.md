# Design: add-reading-time

## Decisions
- D1: `wordCount` lives in `src/word-count.js`: `String(str).trim().split(/\s+/).filter(Boolean).length`.
- D2: `readingTime` lives in `src/reading-time.js` and reuses `wordCount`; the speed defaults to 200 words per minute.
- D3: Both are re-exported from `src/index.js`. No dependencies are added.

## File Changes
- Create `src/word-count.js`, `test/word-count.test.js`.
- Create `src/reading-time.js`, `test/reading-time.test.js`.
- Modify `src/index.js` (two new exports).

## Testing Strategy
vitest unit tests per function, written first (TDD), covering every spec scenario. Run with `npm test`.
