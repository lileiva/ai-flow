# Spec: add-reading-time

## Requirements

### REQ-001: wordCount (MUST)
`wordCount(str)` returns the number of words in `str`. Words are separated by runs of whitespace; leading and trailing whitespace is ignored.

Scenario 1: Counts words
  Given the text "the quick  brown\tfox"
  When wordCount runs
  Then it returns 4

Scenario 2: Empty text
  Given the text "   "
  When wordCount runs
  Then it returns 0

### REQ-002: readingTime (MUST)
`readingTime(str, { wordsPerMinute = 200 } = {})` returns the whole number of minutes needed to read `str`: `Math.ceil(wordCount(str) / wordsPerMinute)`.

Scenario 1: Rounds up
  Given a text of 201 words
  When readingTime runs with the default speed
  Then it returns 2

Scenario 2: Custom speed
  Given a text of 300 words
  When readingTime runs with wordsPerMinute 100
  Then it returns 3

Scenario 3: Empty text
  Given the text ""
  When readingTime runs
  Then it returns 0
