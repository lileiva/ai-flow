# Proposal: add-reading-time

## Intent
Readers of textkit-powered blogs want to know how long a post takes to read. Add two pure helpers: `wordCount` and `readingTime`.

## Scope
In scope: `wordCount(str)` and `readingTime(str, options)` in textkit, exported from `src/index.js`, with vitest tests.
Out of scope: HTML stripping, locale-aware word segmentation, changes to existing functions.

## Risks
- Word splitting on unusual whitespace (tabs, newlines). Mitigation: split on runs of whitespace.
- Rounding surprises for very short texts. Mitigation: round up, and return 0 only for empty text.

## Rollback
Revert the commit that adds `src/word-count.js`, `src/reading-time.js` and the two index exports. No other code depends on them.

## Success Criteria
- `wordCount` and `readingTime` are exported and covered by tests.
- `npm test` passes; existing tests are unchanged.
